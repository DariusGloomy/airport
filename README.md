
Информационная система аэропорта

Как запустить проект у себя

Выполните следующие шаги:

1. Откройте Visual Studio, выберите «Клонирование репозитория» и вставьте ссылку на этот репозиторий.

2. Разверните базу данных
Откройте SQL Server Management Studio (SSMS).
Откройте файл `Database_Script.sql` (он лежит в корне проекта).
Нажмите «Выполнить» (F5). Скрипт сам создаст базу `AirportDB`, все таблицы и заполнит их тестовыми данными.
*(Этот скрипт выполняется только в изначальном создании БД, если ее нет, если вдруг вы запустите его после появления новый данных, то он может их стереть)*

3. Настройте подключение к БД
Откройте файл `App.config` (или `appsettings.json`) в проекте.
Найдите строку подключения (`connectionString`).
Замените имя сервера на то, которое используется у вас в SSMS.

4. Запуск

Тестовые аккаунты (Логин / Пароль)
После развертывания базы данных вы можете войти в систему под следующими пользователями:
Администратор: admin / 1234 (доступ ко всем разделам)
Агент по регистрации: manager / 5678 (рейсы, регистрация, табло)
Аналитик: guest / 9012 (рейсы, аналитика, табло)
Директор: user / 1111 (только табло и отчеты)
